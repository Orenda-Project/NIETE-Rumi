**NEW QUESTION STRUCTURE - IMPORTANT:**
Each question type now has a hierarchical structure with these fields:

1. **"main_question"**: The main heading/instruction for the question type
2. **"question"**: The actual question text
3. **"marks"**: Marks allocated
4. **"lines"**: Integer — number of blank lines a student needs to write their answer. Use **0** when no writing lines are needed (e.g., MCQs, True/False, Match columns, Circle correct, Fill in the blanks). Use a positive integer for questions requiring written answers.
5. **"answer"**: The correct answer. For MCQs/MSQs use Urdu letter labels (e.g., "ب) لاہور"). For True/False write "True" or "False". For Fill in the blanks write the correct word(s). For Match the Column write the correct pairs. For Brief answers/subjective write a concise model answer.
6. **"blooms"**: Bloom's Taxonomy level. REQUIRED for EVERY question. Use one of: "Remember", "Understand", "Apply", "Analyze", "Evaluate", "Create".

BLOOM'S TAXONOMY ASSIGNMENT GUIDE

1. REMEMBER (Retrieval) — Retrieving a pre-stored fact exactly as learned.
2. UNDERSTAND (Translation/Interpretation) — Rephrasing or explaining a concept.
3. APPLY (Implementation) — Using a rule/formula on a new or specific case.
4. ANALYZE (Deconstruction) — Breaking a whole into parts to find patterns.
5. EVALUATE (Judgement/Critique) — Making a choice based on criteria.
6. CREATE (Synthesis) — Building something new by combining parts.

Pipeline Guardrails:
- Complexity ≠ Bloom Level. Do not confuse difficulty with cognitive level.
- The "Newness" Factor: scenario/case study not in training material → at least Apply.
- Verb Neutrality: Look at the object of the verb, not just the verb.
