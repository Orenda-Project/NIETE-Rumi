**NEW QUESTION STRUCTURE - IMPORTANT:**
Each question type now has a hierarchical structure with these fields:

1. **"main_question"**: The main heading/instruction for the question type (e.g., "Choose the correct option")
2. **"question"**: The actual question text
3. **"marks"**: Marks allocated
4. **"lines"**: Integer — number of blank lines a student needs to write their answer. Use **0** when no writing lines are needed (e.g., MCQs, True/False, Match columns, Circle correct, Fill in the blanks). Use a positive integer for questions requiring written answers (e.g., Brief answers, Word Meanings, Word Sentences, Letter/Story/Essay Writing, Comprehension sub-questions). Match the number of lines to the grade level and expected answer length.
5. **"answer"**: The correct answer to the question. REQUIRED for EVERY question. For MCQs/MSQs provide the correct option text (e.g., "b) 4"). For True/False write "True" or "False". For Fill in the blanks write the correct word(s). For Match the Column write the correct pairs (e.g., "Dog → Barks, Cat → Meows"). For Brief answers/subjective write a concise model answer. For Word Meanings write the meaning. For Comprehension sub-questions include the answer in the sub-question object. For writing tasks provide a brief outline or key points.
6. **"blooms"**: Bloom's Taxonomy level for the question. REQUIRED for EVERY question. Use one of: "Remember", "Understand", "Apply", "Analyze", "Evaluate", "Create".

BLOOM'S TAXONOMY ASSIGNMENT GUIDE

1. REMEMBER (Retrieval)
   Cognitive Process: Retrieving a pre-stored fact, date, name, or formula exactly as learned.
   The "Tell": Can be answered by someone who memorized the textbook but doesn't understand it.
   Key Logic: Recognition or Recall.

2. UNDERSTAND (Translation/Interpretation)
   Cognitive Process: Must "digest" and rephrase information; see relationships between concepts.
   The "Tell": If the student explains logic or identifies an example not explicitly in the notes.
   Key Logic: Explaining, Summarizing, or Paraphrasing.

3. APPLY (Implementation)
   Cognitive Process: Takes a rule/formula/method and uses it on a new or specific unseen case.
   The "Tell": "Given [Scenario X], use [Rule Y] to find the result." Calculations or situational execution.
   Key Logic: Executing a procedure in a given context.

4. ANALYZE (Deconstruction)
   Cognitive Process: Breaks a whole into parts to find patterns, biases, or underlying structures.
   The "Tell": Looking at a complex system to find WHY something is happening or how it differs.
   Key Logic: Differentiating, Organizing, or Attributing.

5. EVALUATE (Judgement/Critique)
   Cognitive Process: Makes a choice based on criteria — acts as "the judge."
   The "Tell": No single factual right answer; instead a "most effective" or "best justified" answer.
   Key Logic: Checking, Critiquing, or Justifying a decision.

6. CREATE (Synthesis)
   Cognitive Process: Builds something new by combining parts into a unique whole.
   The "Tell": The output did not exist before the student started.
   Key Logic: Generating, Planning, or Producing.

Pipeline Guardrails:
- Complexity ≠ Bloom Level: A hard "Remember" question (e.g., "What is the 50th decimal of Pi?") is still Remember. Do not confuse difficulty with cognitive level.
- The "Newness" Factor: If a question contains a scenario or case study not in the training material, it must be at least Apply (Level 3).
- Verb Neutrality: Do not trust the verb alone. "Identify the cause" = Analyze. "Identify the date" = Remember. Look at the object of the verb.

Tagging Examples:
- "What year did Pakistan gain independence?" → Remember (recalling a memorized fact)
- "Calculate the force needed to move a 5kg block with friction coefficient 0.3" → Apply (applying a formula to a specific instance)
- "Which of the following is an example of an isotope?" (example not taught in class) → Understand (classifying a new instance using conceptual rules)
- "Based on the two reports provided, which author shows a commercial bias?" → Analyze (detecting underlying intent/structure)
