### OUTPUT FORMAT
You MUST return the exam as a JSON object with the following structure for Maths:

**CRITICAL JSON SYNTAX REQUIREMENTS**:
- Use the EXACT key names shown below (case-sensitive)
- **EVERY property MUST be separated by a comma (,)**
- Use double quotes for all strings and property names
- Empty arrays [] are fine for unused categories

**REQUIRED FIELDS ON EVERY MATHS QUESTION OBJECT:**
1. **"main_question"**: Heading/instruction for the question type
2. **"question"**: The actual question text (omit for question types that use other content fields like Match the Column)
3. **"marks"**: Marks allocated (integer)
4. **"lines"**: Integer — number of blank lines a student needs to write their answer. Use 0 for objective question types (MCQs, MSQs, True/False, Fill in the blanks, Match the Column, Mental Math, Sequences). Use a positive integer for subjective written answers (Short Questions, Restricted Response, Word Problems, Graphs & Geometric Problems).
5. **"answer"**: The correct answer to the question. REQUIRED for EVERY question. For MCQs/MSQs provide the correct option text (e.g., "b) 60"). For True/False write "True" or "False". For Fill in the blanks write the correct number/word(s) that fill the blank (e.g., "15" for "25 + ___ = 40"). For Match the Column write the correct pairs (e.g., "Triangle → 3, Square → 4, Pentagon → 5"). For Mental Math/Sequences write the numeric answer or completed sequence (e.g., "2, 4, 6, 8, 10"). For Short Questions / Restricted Response / Word Problems / Graphs & Geometric Problems write a concise step-by-step model solution ending with the final numeric answer (e.g., "48 - 19 = 29 apples"). Use plain text math notation — no LaTeX.
6. **"blooms"**: Bloom's Taxonomy level. REQUIRED for EVERY question. Use one of: "Remember", "Understand", "Apply", "Analyze", "Evaluate", "Create".

🚨 **SPECIAL RULE — LONG QUESTION:**
"Long Question" in subjective is ALWAYS a JSON **object** (NOT an array) with exactly two sub-keys:
- "Word problems": array of word problem questions
- "Graphs & Geometric Problems": array of graph/geometry questions

**CRITICAL - Image Key ("image") for Maths:**
- Use `"image"` as the field name. The value is a prompt for an image generation model.
- Style rule for ALL images: black and white, clean simple outlines, no colors, no shading, no gradients, no watermarks, no text overlays. Print-friendly for elementary school students.

When to add the "image" key in Maths:
1. **SEEN questions:** The textbook OCR may contain image descriptions marked as "Object: ...", "Picture shows: ...", or similar. Add `"image"` ONLY if the `Object:` / picture description is **directly relevant to the question being asked** — i.e. the question is about that diagram or visual. DO NOT add `"image"` for `Object:` entries that are merely decorative illustrations unrelated to the question. When you do add it, use the OCR description as the basis for the image prompt.
2. **Counting objects** (grades 1–2): Add "image" showing the objects being counted.
3. **Calculation/operation** (grades 1–2): Add "image" showing the operation visually (e.g. groups of objects for multiplication).
4. **Measurement, length, capacity** (grades 1–2): Add "image" showing the measuring scenario (ruler, containers, etc.).
5. **Time/clock** (grades 1–4): Add "image" showing a clock face with the relevant time.
6. **Shapes and position** (grades 1–3): Add "image" showing the relevant shape(s) or positional diagram.
7. **Graphs** (grades 3–5): Add "image" showing a blank or sample graph/chart relevant to the question.
8. **Fractions** (grades 2–5): Add "image" showing a shape divided into the relevant fraction parts.
9. **Geometry and angles** (grades 4–5): Add "image" showing the geometric figure or angle diagram.
10. **Perimeter and area** (grade 5): Add "image" showing the labeled shape with dimensions.
11. **DO NOT** add "image" for purely text-based calculations or word problems that do not benefit from a diagram.

Format: `"image": "Black and white line drawing of [description]. Clean outlines, no shading, print-friendly, elementary school style."`


🚨 **ANSWER KEY REQUIRED**: EVERY question object MUST carry an "answer" field (a string) — every type, seen and unseen, with no exceptions:
- MCQs: the full text of the correct option exactly as it appears in "options" (e.g. "b) 4"); MSQs: every correct option, comma-separated.
- True/False: "True" or "False".
- Fill in the blanks / Missing Letters: the word(s) or letters that fill each blank.
- Match the Column: every correct pair, "left: right", comma-separated.
- Questions with a "words" list (Word Meanings, Word Sentences, word bank): one answer per word — its meaning or a model sentence — as "word: answer" lines.
- Brief/short/long answers and word problems: a concise model answer or worked solution.
- Any writing task (essay, story, letter, application, paragraph, picture description): a short model answer or the key points a good answer must contain.
- Comprehension: put the "answer" inside EACH sub-question object in "questions", not on the passage.
