Learning outcome · M-01-PA-01
  • Every pattern is built from one small unit that keeps repeating.
  • Box the unit, chant it, and then look at where the chant stopped: if it stopped at the END of the box, go back to the start of the unit; if it stopped in the MIDDLE of the box, finish the box.
  • Never choose by the last shape you happen to see.

Draw a chalk box around the first triangle and circle, and a second box around the next triangle and circle.
The boxes are full. The next box starts again, so the next shape is the first one in the box: a triangle. That is choice B.
Some of you may think the next shape is a circle, because a circle came last. But the last box is full, so we go back to the start of the unit.
Chalk a triangle in the question-mark place and write B beside it.
Point to question 4: Bunty's books, Big, Small, Big, Small.
Big, small is the unit. The second box is full, so we go back to the start. The next book is Big.
What is the unit in Bunty's books?
Big, small.
Notice what I did each time: I said it from the start, boxed the unit, and went back to the start of the box.
I Do Worked example
  1. Textbook p.272 Q2 third pattern: triangle, circle, triangle, circle, ?
  2. Say it from the start and box the unit: triangle, circle.
  3. Both boxes are full, so go back to the start of the unit. Answer: triangle (choice B).

Ask this
  • Check for understanding. Ask: "How did you know the next shape?" Expected: "I boxed the unit and the last box was full, so I went back to the start."
  • If a pupil says "circle, because the last one was a circle", say: "Chant the unit with me: triangle, circle. Is the box full? Then where do we go?" Then ask again.
  • Ask: "What is the unit in the books?" Expected: "Big, small."
  • If a pupil says "small", say: "Say it from the start: big, small, big, small. The box is full. Where do we go?"

Common mistakes and the question you ask back
✗ What pupils say or write

The next shape is a circle because the last one was a circle.

✓ You ask

Chant the unit from the start. Is the box full? Then where do we go?

✗ What pupils say or write

The squares are getting bigger, so the next is a bigger square.

✓ You ask

Chant small, medium, large. When the unit is full, where do we go? Back to small.

Differentiation
If stuck
  • Named strategy: Box and Chant.
  • Draw the chalk box around each full unit for the pupil. Then the pupil puts a finger on the first shape and chants the unit aloud.
  • The pupil says whether the box is full or not full, then names the next shape.
  • Start with the two-shape triangle, circle pattern before the three-shape star, star, diamond.

CCheck 5 min
Exit ticket
1.Read out the success criteria: "You have done it if you can say the unit and name the next one."
Pupils show thumbs up, sideways or down to predict how they will do.
Chalk on the board: banana, banana, apple, banana, banana, ? Pupils write the unit and draw the next fruit. → The unit is banana, banana, apple, and the next is an apple. If a pupil draws a banana, they went by the last fruit; practise boxing the unit tomorrow.
HHomework
Homework
  • At home, find a pattern in a rug, a plate or a cloth.
  • Draw the unit twice on a slate or in a notebook and draw the next shape.
Coaching corner

Ask yourselfWatch which pupils choose the next shape by the last shape they see instead of by the unit.
Note whether pupils can hold a three-item unit (star, star, diamond; ball, box, cup) as well as a two-item one.
If many pupils needed the chalk box, spend five minutes boxing units tomorrow before the new work.
If pupils argued about Jump or Clap in Q5, that was good mathematics: ask each to name the unit they used.
